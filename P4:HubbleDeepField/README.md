# Project 4: Hubble Ultra Deep Field 
## Overview
This project aims to recreate the 2004 image of the Hubble Ultra Deep Field (HUDF), a world renowned image which changed the landscape of astrophysics reaseach and has changed the way we think about the early Universe and the vastness of space. The project downloads image data from the Hubble Space Telescope, pieces it togeher while still preserving the RA and DEC coordinates, and then ultimatly displays the final image with the same breathtaking and intrinsic qualities as when first realesed 20 years ago. Then going a step furhter this project overlays redshift data taken in a 2006 study of the HUDF and overlays it onto the image so that viewers can see just how much data we have on this relitvlity little piece of sky. The aim is to mainitain the coordiante system of the image so that the research conducted perfectly fits into our image so that any future astronomers can look and see just how many galasxies there are and use redshift data for future explorations. 
## Objectives
1. Create a RGB image of the HUDF using the Hubble Space Telescope 
2. Overlay Specroscopic and Photmetric Redshift data onto the image 
## Data Set 
The data used in this project is downlaoded as FITS files from the Hubble Space Telescope. Secondly the redhsift data is taken from a 2006 survery conducted by Dan Coe, Narciso Benítez, et all. The citation is provided below. 
## Analysis 
This project showcases many skills but the top involve a mastery of the SkyCord pacakge used in astromy to mainitn coordiante systems across several images so that a mosaic can be ulitmatly be displayed which combines data from a variety of differetn sources. In addition a fundamental understanding of how data is taken and stored in FITS files is necessary to create this image and overlay the data. Overall this project is an exercise in fundamental astronomical computing cooncepts and shows how to effectivly study data.
